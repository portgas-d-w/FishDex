# 📋 Vision validée

```
SYSTÈME DE COLLECTIONS = "Pokédex régionaux par famille de pêche"

OBJECTIFS :
✓ Permettre à chaque pêcheur de "compléter" SA spécialité sans pression
✓ Anti-frustration : un carpiste n'est pas forcé de pêcher du carnassier
✓ Fierté tranquille : "Maître Carpiste" = vrai accomplissement
✓ Système Mirage caché : surprise émotionnelle pour les chanceux
```

## ✅ Décisions validées

```
🏗️ STRUCTURE
• 3 collections principales : Paisibles, Prédateurs, Eaux vives
• Mirages cachés dans chaque collection (non comptés dans la complétion)
• ~100 espèces visibles + ~10-15 Mirages = ~115 espèces totales

🐟 ESPÈCES
• Multi-collections possible (1 espèce peut être dans 2 collections)
• 1 capture = débloque dans toutes ses collections d'appartenance
• Affichée dans chaque collection (vues séparées)

🎨 UX
• FishDex : Toggle "Ma Collection" / "Toutes les espèces"
• Profil : section "Ma voie" + "Autres voies"
• Voie principale changeable avec confirmation forte

🏆 RÉCOMPENSES
• Badge "Maître [Collection]" à 100% (hors Mirages)
• Badge "Complétionniste" si 100% partout
• Mirages = bonus pur (105/100, 110/100...)
```

```sql
-- ═══════════════════════════════════════
-- TABLE : collections (les 3 grandes catégories)
-- ═══════════════════════════════════════

CREATE TABLE public.collections (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug TEXT UNIQUE NOT NULL,           -- 'paisibles', 'predateurs', 'eaux_vives'
  name TEXT NOT NULL,                   -- 'Paisibles', 'Prédateurs', 'Eaux vives'
  description TEXT,
  emoji TEXT,                           -- '🐟', '🦈', '🌊'
  color_hex TEXT,                       -- couleur de la collection
  display_order INTEGER NOT NULL DEFAULT 0,
  is_active BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- Insertion des 3 collections
INSERT INTO public.collections (slug, name, description, emoji, color_hex, display_order) VALUES
  ('paisibles', 'Paisibles', 'L''école traditionnelle. Pêche au coup, étangs et lacs calmes, gros poissons paisibles.', '🐟', '#06b6d4', 1),
  ('predateurs', 'Prédateurs', 'Les chasseurs des rivières et lacs. Pêche au leurre, traque, combat.', '🦈', '#a855f7', 2),
  ('eaux_vives', 'Eaux vives', 'Rivières de montagne, eaux froides oxygénées. Truite, mouche, technique pure.', '🌊', '#10b981', 3);


-- ═══════════════════════════════════════
-- TABLE PIVOT : species ↔ collections (many-to-many)
-- ═══════════════════════════════════════

CREATE TABLE public.species_collections (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  species_id UUID NOT NULL REFERENCES public.species(id) ON DELETE CASCADE,
  collection_id UUID NOT NULL REFERENCES public.collections(id) ON DELETE CASCADE,
  is_primary BOOLEAN DEFAULT FALSE,    -- collection "principale" de l'espèce
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(species_id, collection_id)
);

CREATE INDEX species_collections_species_idx ON public.species_collections(species_id);
CREATE INDEX species_collections_collection_idx ON public.species_collections(collection_id);


-- ═══════════════════════════════════════
-- AJOUT : species.is_mirage (flag Mirage caché)
-- ═══════════════════════════════════════

-- Note : si la rareté 'shiny' est renommée 'mirage' en H1, 
-- ce champ peut être déduit de species.rarete = 'mirage'
-- Sinon, on ajoute un flag explicite :

ALTER TABLE public.species 
  ADD COLUMN IF NOT EXISTS is_hidden_in_dex BOOLEAN DEFAULT FALSE;

-- Si l'espèce.rareté = 'mirage', alors is_hidden_in_dex = TRUE par défaut
-- → Compteur de complétion : "X / total_visible" où visible = NOT is_hidden_in_dex


-- ═══════════════════════════════════════
-- PROFILES : voie principale + flag onboarding collection
-- ═══════════════════════════════════════

ALTER TABLE public.profiles 
  ADD COLUMN IF NOT EXISTS preferred_collection_slug TEXT REFERENCES public.collections(slug);

ALTER TABLE public.profiles 
  ADD COLUMN IF NOT EXISTS collection_choice_completed BOOLEAN DEFAULT FALSE;


-- ═══════════════════════════════════════
-- RLS POLICIES
-- ═══════════════════════════════════════

ALTER TABLE public.collections ENABLE ROW LEVEL SECURITY;

CREATE POLICY "All authenticated read collections" 
  ON public.collections FOR SELECT 
  TO authenticated 
  USING (TRUE);

ALTER TABLE public.species_collections ENABLE ROW LEVEL SECURITY;

CREATE POLICY "All authenticated read species_collections" 
  ON public.species_collections FOR SELECT 
  TO authenticated 
  USING (TRUE);


-- ═══════════════════════════════════════
-- VUE UTILE : progression par collection pour un user
-- ═══════════════════════════════════════

CREATE OR REPLACE VIEW public.user_collection_progress AS
SELECT 
  c.id AS collection_id,
  c.slug AS collection_slug,
  c.name AS collection_name,
  cat.user_id,
  
  -- Total d'espèces visibles dans la collection (hors Mirages cachés)
  COUNT(DISTINCT sc.species_id) FILTER (
    WHERE NOT s.is_hidden_in_dex
  ) AS total_visible,
  
  -- Total d'espèces capturées par l'user dans cette collection
  COUNT(DISTINCT cat.species_id) FILTER (
    WHERE NOT s.is_hidden_in_dex
  ) AS captured_visible,
  
  -- Total de Mirages capturés (en bonus)
  COUNT(DISTINCT cat.species_id) FILTER (
    WHERE s.is_hidden_in_dex
  ) AS mirages_captured,
  
  -- Pourcentage de complétion (sur le visible)
  CASE 
    WHEN COUNT(DISTINCT sc.species_id) FILTER (WHERE NOT s.is_hidden_in_dex) = 0 THEN 0
    ELSE ROUND(
      100.0 * COUNT(DISTINCT cat.species_id) FILTER (WHERE NOT s.is_hidden_in_dex) 
      / COUNT(DISTINCT sc.species_id) FILTER (WHERE NOT s.is_hidden_in_dex),
      1
    )
  END AS completion_percent

FROM public.collections c
JOIN public.species_collections sc ON sc.collection_id = c.id
JOIN public.species s ON s.id = sc.species_id
LEFT JOIN public.catches cat ON cat.species_id = s.id
GROUP BY c.id, c.slug, c.name, cat.user_id;

-- Index pour performance
CREATE INDEX IF NOT EXISTS catches_user_species_idx ON public.catches(user_id, species_id);
```

```
═══════════════════════════════════════

═══════════════════════════════════════
VISION DU SYSTÈME
═══════════════════════════════════════

Pourquoi des collections ?
- Un carpiste ne pêche pas de truite. C'est OK.
- Chaque pêcheur doit pouvoir "compléter" SA spécialité sans pression.
- Le FishDex global existe, mais chaque collection est aussi complétable.

Les 3 collections :
1. 🐟 Paisibles  : Cyprinidés + Carpistes (~45 espèces)
2. 🦈 Prédateurs : Carnassiers (~25 espèces)
3. 🌊 Eaux vives : Salmonidés (~20 espèces)

+ Mirages cachés dans chaque collection (~5 par catégorie)
  → Non comptés dans la complétion mais visibles une fois capturés
  → Permet d'aller au-delà du 100% (ex: 50/45 espèces Paisibles)

═══════════════════════════════════════
COMPORTEMENT À IMPLÉMENTER
═══════════════════════════════════════

ONBOARDING COLLECTION
- À l'inscription (ou première connexion après migration) :
  Écran "Quelle est ta voie de pêche ?"
- 4 choix : 🐟 Paisibles / 🦈 Prédateurs / 🌊 Eaux vives / ✨ Tout explorer
- Stocké dans profiles.preferred_collection_slug
- Si "Tout explorer" : preferred_collection_slug = NULL
- Marquer profiles.collection_choice_completed = TRUE

FISHDEX V3 — PAGE
- Toggle principal : "Ma Collection" (par défaut) / "Toutes les espèces"
- "Ma Collection" :
  • Affiche les espèces de la voie principale uniquement
```

# 🏆 Système de titres par collection

```
ÉVOLUTION DES TITRES (par collection) :

Étape 1 - 1ère capture     → "Curieux"
Étape 2 - 25% complété     → "Initié"
Étape 3 - 50% complété     → "Apprenti"
Étape 4 - 75% complété     → "Expert"
Étape 5 - 100% complété    → "Maître Paisibles" (etc.)

CALCUL TYPESCRIPT :
function getCollectionTitle(completion_percent: number, collection_slug: string): string {
  if (completion_percent === 0) return 'Découvreur';
  if (completion_percent < 25) return 'Curieux';
  if (completion_percent < 50) return 'Initié';
  if (completion_percent < 75) return 'Apprenti';
  if (completion_percent < 100) return 'Expert';
  return `Maître ${collectionName[collection_slug]}`;
}
```
